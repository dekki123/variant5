# Практическая работа №8-9, вариант 5 (C#)

Для двух вещественных массивов (до 10x10) найти количество столбцов,
содержащих только неположительные элементы.

- `Logic.cs` - логика (процедура проверки столбца)
- `IoUtils.cs` - ввод, валидация, вывод
- `Tests.cs` - тесты
- `Program.cs` - главный модуль

Запуск: `dotnet run`, `dotnet run -- --demo`, `dotnet run -- --test`.
